## About

ChatQT is a native KDE application that provides a simple and intuitive interface for chatting with AI models via OpenAI-compatible APIs. Built specifically for the KDE Plasma desktop environment, it integrates seamlessly with your workflow.

### Features

- **Multiple provider support** - Connect to OpenAI, OpenCode, or any OpenAI-compatible API
- **Simple interface** - Clean and intuitive design built with Kirigami
- **Native KDE integration** - Built with Qt/QML for seamless Plasma desktop experience
- **Lightweight** - Minimal resource usage for efficient AI conversations
- **Customizable settings** - Configure endpoints, models, and parameters
- **Chat management** - Clear chat history and control auto-scroll behavior
